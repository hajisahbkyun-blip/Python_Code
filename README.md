# 🐍 Python Learning Journey & Code Repository

Welcome to my Python Code Repository! This repository documents my journey of mastering Python programming, from the fundamentals to advanced concepts. It serves as a personal knowledge base and a portfolio of the exercises, practice problems, and projects I have completed.

## 🚀 About This Repository

This repository is organized topic-wise to make it easy to navigate and review specific concepts. Each folder contains well-commented code, practice questions, and solutions that I have implemented while learning.

## 📂 Repository Structure

Here is a brief overview of the topics covered in this repository:

| Folder/File                                 | Description                                                                                                  |
| :------------------------------------------ | :----------------------------------------------------------------------------------------------------------- |
| `01_Variable and Data Types`                | Basics of Python variables, data types (int, float, string, boolean), and type conversion.                   |
| `02_Escape Sequences and Operators`         | Usage of escape sequences (`\n`, `\t`) and various operators (Arithmetic, Assignment, Comparison, Logical).  |
| `03_Conditional_Statements`                 | Implementation of `if`, `elif`, `else`, nested conditions, and the ternary operator.                         |
| `04_WHILE_loop`                             | Practice problems and logic building using `while` loops.                                                    |
| `05_For_loop`                               | Iteration using `for` loops, `range()` function, and looping through sequences.                              |
| `06_Break _Continue_ statement/Nested Loop` | Advanced loop control using `break`, `continue`, and implementation of nested loops for pattern printing.    |
| `07_Functions`                              | Writing reusable code with functions, parameters, return values, and the DRY principle.                      |
| `Practice_Questions`                        | A dedicated folder containing solutions to various practice problems covering all the topics learned so far. |

_(Note: The structure is continuously updated as I progress further into my learning journey.)_
